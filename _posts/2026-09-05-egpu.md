### 不买不行的

如前面所说，我自以为对电脑性能要求不高，同时也是高估了那颗 780M 核显的能力，买了一款轻薄本。事实证明这根本不够用！

在被60帧的 FF14 折磨得不像样子之后，我购买了华为的显卡魔方，RX 7600M XT 内置240w电源。

那我不炸了吗！抛开性能不说，处于能用的水平。最大的这个问题就是240w电源和散热不知道谁出问题了，游玩大型游戏经常出现电脑重启的问题。

忍无可忍之后，挂小黄鱼上面卖了。另外购置了 机魂联盟NanoXSV2 扩展坞和 RX 9060 XT 8G  显卡。

![](https://xiaochopin.dpdns.org/1788606753769.webp)

### 性能够用

9060XT 的性能还是挺强悍的，笔记本内屏 Time Spy 分数接近一万二，外屏扩展模式可以达到一万四千多，如果是外屏独占分数还能更高。

目前测试了2K分辨率的 FF14（原生分辨率）和绝地潜兵2（FSR4质量），这两款 CPU 瓶颈更严重的游戏均能达到理想的帧数，并且绝地潜兵2在 AFMF2.1 帧生成的加持下能更加舒服地游玩。

### 带宽问题

由于雷电4显卡坞目前只能以 PCIe 3.0 x4 的模式连接，低带宽使一些大型游戏会出现不同程度的掉帧，比如 COD17 的材质质量只能开到“低”，如果开“中”的话会有隔十几秒帧数突然帧数触底一瞬间的问题，不过这种情况算是少数。

>主要是我近期玩的大型游戏不多，没什么能测试的。

还是 COD17，会出现帧数异常低的情况，重连显卡坞可以解决。

### 显卡坞问题

机魂联盟家的这款显卡坞的跟随启动功能在我这里并不可用，会出现无法开机的情况（怎么华为那个显卡坞就没事。。。），应该是卡自检了。

每次休眠使用如下脚本断开显卡坞再休眠：

```
@echo off
net session >nul 2>&1
if %errorlevel% neq 0 (
    echo Please run as administrator.
    pause
    exit /b 1
)

echo Ejecting eGPU ...
powershell -ExecutionPolicy Bypass -File "D:\Apps\EjectGPU.ps1"

echo Hibernating ...
shutdown /h
```

其中用到的EjectGPU.ps1如下：

```

$deviceName = "AMD Radeon RX 9060 XT"

$dev = Get-PnpDevice -FriendlyName $deviceName -ErrorAction SilentlyContinue

if ($dev) {
    Write-Host "Disabling: $deviceName ..." -ForegroundColor Yellow
    Disable-PnpDevice -InstanceId $dev.InstanceId -Confirm:$false
    Write-Host "Disabled. Waiting 2 seconds..." -ForegroundColor Green
    Start-Sleep -Seconds 2
} else {
    Write-Host "Device '$deviceName' not found." -ForegroundColor Cyan
}
```

开机的时候使用：

```
@echo off
net session >nul 2>&1
if %errorlevel% neq 0 (
    echo 请以管理员身份运行此脚本！
    echo 右键点击该文件 -> "以管理员身份运行"
    pause
    exit /b 1
)

echo 正在处理 eGPU: AMD Radeon RX 9060 XT ...
powershell -Command "Add-Type -AssemblyName System.Windows.Forms; Add-Type -AssemblyName System.Drawing; function Send-Notification($title,$msg) { $notify=New-Object System.Windows.Forms.NotifyIcon; $notify.Icon=[System.Drawing.Icon]::ExtractAssociatedIcon((Get-Command powershell).Path); $notify.BalloonTipTitle=$title; $notify.BalloonTipText=$msg; $notify.Visible=$true; $notify.ShowBalloonTip(5000); Start-Sleep -Milliseconds 500 }; $dev=Get-PnpDevice -FriendlyName 'AMD Radeon RX 9060 XT' -ErrorAction SilentlyContinue; if (-not $dev) { Write-Host '未找到设备，请检查名称是否正确。' -ForegroundColor Cyan; Send-Notification 'eGPU 错误' '未找到设备 AMD Radeon RX 9060 XT，请检查名称。' } else { Write-Host ('当前设备状态: '+$dev.Status) -ForegroundColor Yellow; try { Disable-PnpDevice -InstanceId $dev.InstanceId -Confirm:$false -ErrorAction Stop; Write-Host '已执行禁用操作。' -ForegroundColor Gray } catch { Write-Host ('禁用时出现提示（可能已禁用）: '+$_.Exception.Message) -ForegroundColor Gray }; Start-Sleep -Seconds 2; try { Enable-PnpDevice -InstanceId $dev.InstanceId -Confirm:$false -ErrorAction Stop; Write-Host '已成功启用设备。' -ForegroundColor Green; Send-Notification 'eGPU 状态' 'AMD Radeon RX 9060 XT 已重置并启用。' } catch { Write-Host ('启用设备失败: '+$_.Exception.Message) -ForegroundColor Red; Send-Notification 'eGPU 错误' '启用 AMD Radeon RX 9060 XT 失败，请检查设备管理器。' } }"
```

该脚本会自动启用，或者重启显卡设备。

### Windows太坏了

莫名其妙的卡顿也是不得不品鉴的一环，虽然只局限于扩展模式。

其实选择“仅第二屏幕”可以规避很多问题，但是我非常需要笔记本屏幕作为我的副屏使用😡😡😡。

1. 副屏不能开动态壁纸（疑似可变刷新率导致）。

2. 副屏不能用浏览器放视频（关闭硬件加速）。

3. 莫名的窗口拖动卡顿（修改注册表缓解）。

4. 副屏开了个 Windows设置 导致的窗口拖动卡顿（Windows 你咋这么多事）。

关闭 OMF 缓解某些情况下的窗口拖动卡顿：

```
Windows Registry Editor Version 5.00

[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\Dwm]
"OverlayMinFPS"=dword:00000000
```
